# Dynamic Todo List Web App ✅

A clean, modern, and interactive browser-based Todo List application designed to manage daily routines. It features local persistence, progress tracking, and celebratory confetti effects.

## 🌟 Key Features
- **Task Management**: Easily add and mark tasks as completed.
- **LocalStorage Persistence**: Tasks are saved automatically in your browser, meaning they persist even after page refresh.
- **Live Progress Bar**: Visually displays the percentage of tasks completed.
- **Stats Counter**: Live display of completion ratio (e.g. `2/5` completed).
- **Celebration Effect**: Triggers satisfying confetti particles when you complete all tasks, using the `canvas-confetti` library.

## 🛠️ Tech Stack
- **HTML5**: Form-based structure.
- **CSS3**: Custom stylized interface with stats bars and modern input UI.
- **JavaScript**: LocalStorage interactions, DOM manipulations, and event handling.
- **Third-Party CDN**: Canvas-Confetti browser bundle.
